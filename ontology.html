팔란티어 개념이 사이트에서의 대응
Object Type (실세계 개체의 스키마)회사 · 법률 · 제도·이슈 · 기관 · 수치 · 주제 · 산업군 · 기사. 기사 본문에서 자동 추출
Property (개체의 속성)기사 수, 보도 기간, 주제 분포, 산업군 분포, 수치의 문맥
Link Type (개체 간 관계)같은 기사에 함께 등장하면 연결(굵기=횟수). 기사 ↔ 개체는 '언급' 관계
Action (개체에 대한 작업)연결 관계 JSON 내보내기, 기사 목록 복사, 경로 찾기에 지정
Function (로직)공동 언급 집계, 최근 7일 급상승 계산, 두 개체 사이 최단 연결 경로(BFS) 탐색

※ 추출은 사전(회사·법령·기관·이슈 목록)과 패턴(수치·법령명) 기반이라 누락이나 오탐이 있을 수 있습니다. 사전은 코드의 COMPANIES / LAWS / ISSUES / AGENCIES 목록으로 계속 보강할 수 있습니다.
